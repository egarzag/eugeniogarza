# Personal Academic Website

Static bilingual website for Eugenio G. Garza Garza.

## Files

- `index.html`: page structure and bilingual content.
- `styles.css`: visual system, responsive layout, typography, and components.
- `app.js`: language switcher and small dynamic behavior.
- `assets/eugenio-garza.jpeg`: portrait used on the homepage.
- `documents/garza-cv.pdf`: downloadable CV.

## Local Preview

Open `index.html` directly in a browser, or run a local static server from this folder.
